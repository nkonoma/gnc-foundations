## GNC Foundations

This repository rebuilds core guidance, navigation, and control concepts
through from-scratch MATLAB implementations.

### Topics
- Numerical integration (Euler, RK4)
- Linear dynamics and control
- State estimation (Kalman Filter)

### Key lessons
- Numerical stability depends strongly on integration method and step size
- Poor noise modeling causes estimator divergence
- Simple controllers often outperform complex ones when tuned correctly
